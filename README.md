# Linux Server Administration Lab

## Project Overview
This project demonstrates basic Linux server administration using Rocky Linux.

## Tasks Performed
- Created Linux users and groups
- Configured user and group membership
- Created application directories
- Configured ownership using chown
- Configured permissions using chmod
- Configured ACL using setfacl and getfacl
- Installed and configured Apache HTTP Server
- Configured SSH service
- Configured firewall using firewalld
- Performed system monitoring
- Checked system logs
- Created and tested project backup

## Environment
- Operating System: Rocky Linux
- Virtualization: VMware Workstation
- Web Server: Apache HTTP Server
- Firewall: firewalld
